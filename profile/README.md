## Sobre a TundraLab

A **TundraLab** é uma software house fundada e mantida por **Gustavo Henrique Novaes Gomes** ([`@GustaHerin`](https://github.com/GustaHerin)).

Nosso trabalho se divide em duas frentes que caminham juntas:

- **Produtos comerciais e software sob medida:** desenvolvimento de aplicações desktop, web e sistemas completos pensados para resolver problemas reais com código limpo, interface cuidada e foco em desempenho.
- **Projetos open source:** utilitários, extensões e ferramentas abertas para a comunidade, focadas em praticidade e uso no dia a dia.

## Visão

Software bom precisa funcionar bem na prática, sem excesso e sem depender de camadas pesadas quando uma solução direta resolve melhor. A TundraLab existe para construir ferramentas próprias, manter produtos comerciais sustentáveis e devolver para a comunidade código aberto útil e bem acabado.
